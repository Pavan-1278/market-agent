# Skill: SEC Filing Analysis

## Goal

Identify material investor-relevant information in an SEC filing.

## Focus On

- Earnings or financial changes
- Guidance
- Material agreements
- Acquisitions
- Securities issuance
- Insider transactions
- Executive changes
- Legal/regulatory developments
- Risk changes
- Material customer or supplier developments

Ignore routine boilerplate unless it materially changed.

## Output

Return:

- filing_type
- importance: 1–10
- affected
- key_change
- why_read
